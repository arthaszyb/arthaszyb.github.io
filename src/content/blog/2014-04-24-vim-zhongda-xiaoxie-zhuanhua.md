Vim 中大小写转化的命令是 `gu` 或 `gU`。形象一点的解释就是：小 u 意味着转为小写；大 U 意味着转为大写。剩下的就是对这两个命令的限定，通过限定操作的行、字母、单词等范围。

## 整篇文章大小写转换

**转为小写**

打开文件后，键入：`ggguG`

命令分解：
- `gg` = 光标到文件第一个字符
- `gu` = 把选定范围全部小写
- `G` = 到文件结束

**转为大写**

打开文件后，键入：`gggUG`

命令分解：
- `gg` = 光标到文件第一个字符
- `gU` = 把选定范围全部大写
- `G` = 到文件结束

## 单词大小写转换

| 命令 | 说明 |
|------|------|
| `guw`、`gue` | 光标后面的单词转为小写 |
| `gUw`、`gUe` | 光标后面的单词转为大写 |
| `gu5w`、`gu5e` | 光标后面 5 个单词转为小写 |
| `gU5w`、`gU5e` | 光标后面 5 个单词转为大写 |

## 行和范围大小写转换

将光标定位到想转换的行上，键入命令：

| 命令 | 说明 |
|------|------|
| `1gU` | 从光标所在行往下一行进行小写到大写的转换 |
| `10gU` | 进行 11 行的小写到大写的转换 |
| `gU0` | 从光标所在位置到行首，都变为大写 |
| `gU$` | 从光标所在位置到行尾，都变为大写 |
| `gUG` | 从光标所在位置到文章最后一个字符，都变为大写 |
| `gU1G` | 从光标所在位置到文章第一个字符，都变为大写 |
