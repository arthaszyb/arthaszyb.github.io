## CPU 使用率

- `%CPU` 是由每个核的 CPU 占用率之和算出来的
- `total_pcpu` 累加了每个线程对每个核的使用率
- `%CPU` 的最大值 = CPU 核数 × 100%

## load 值

- load 值表示等待运行的进程数
- 最理想的状态：**load = CPU 核数**，这时每个任务分配一个核，没有任何竞争
- load ÷ CPU 核数 > 5 表示系统在超负荷运转

系统每隔 5 秒钟检查一次活跃的进程数，根据这个数值算出 load。

## top 命令

在 top 中按数字 `1` 可以查看每个 CPU 的负载。
