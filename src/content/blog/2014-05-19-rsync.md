**利用服务端配置的同步池进行同步（无需系统账号密码）**

```bash
rsync --port=8873 -oa bugtrace.tgz 10.128.34.67::cfs\backup/pcmgr\svr/bugtrace/bak
```

**已知系统账号密码，可直接同步任意目录**

```bash
rsync --port=8873 -avz bugtrace.tgz root@10.128.34.67:/data/pcmgr_svr/bugtrace/bak
```

**开机时启动一项任务**

除了在 rc.local 中添加外，还可用 crontab -e 搞定：

```bash
@reboot /usr/local/services/XXX.sh
```
